The Bach composition itself is public domain. The MIDI transcription and the generated
`bach-english-suite-no2-prelude-bwv807-data.js` copy are distributed under the license above.
The JavaScript copy exists so the game can still play its BGM when `index.html` is opened
directly with the `file://` protocol. The browser renders the MIDI notes at runtime with a
lightweight Web Audio space synthesizer (glassy carrier, octave shimmer, stereo placement,
and a short feedback echo); no third-party audio recording is bundled.
